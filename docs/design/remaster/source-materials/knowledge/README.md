# 三国知识资料层

这一目录把《三国演义》120 回、《三国志》65 卷及官方《成语典》数据整理成可检索、可回到原文的 JSONL。目标是为剧情、英雄视觉、台词、场景、音乐和卡牌素材提供证据，不是把自动命中包装成历史结论。

## 证据层级

同一人物或事件可能同时存在数种版本，使用时必须保留 `evidenceLayer` 或 `work`：

1. `history-main`：陈寿《三国志》正文。
2. `pei-note`：裴松之注所引《江表传》《汉晋春秋》《云别传》等材料；它们不是陈寿正文。
3. `romance`：毛宗岗评改 120 回本的文学叙事，适合戏剧性设计，不可自动写成史实。
4. `later-*`：后世成语、俗语或概括。确切早期出处未定者明确标为 `unresolved`。

`source.sourcePage` 指向维基文库对应回/卷，`passage` 或 `excerpt` 保存上下文。正式资产还应记录所用语料 SHA-256、提示词和生成参数，才能在文本更新后重现。

## 人物相貌资料怎么用

`visual-passages-curated.jsonl` 把“脸和体型”与“服饰装备”拆开。例如：

- 刘备同时保留《演义》与《三国志·先主传》的相貌文字，可以比较文学加工。
- 赵云“姿颜雄伟”来自裴注引《云别传》，不是陈寿正文。
- 孙权的《江表传》材料是“方颐大口，目有精光”，《演义》才形成“碧眼紫髯”的强识别造型。
- 黄月英“黄头黑色”来自裴注引《襄阳记》中黄承彦自述；原文的“丑”是历史语境中的评价，不应直接变成现代审美结论。
- 大乔、小乔在《周瑜传》中只合称“皆国色”，没有可据以还原的独立五官。
- 祝融只有飞刀、长标和坐骑等装束证据；资料明确标为 `attire-and-equipment`，不虚构相貌。

古籍中的“七尺、八尺、九尺”受时代尺度、文本修辞和版本影响，不应直接乘一个固定系数换算成现代身高。可把它理解为人物间的相对体量与文学造型意图。

查询一个人物的校准资料：

```sh
jq -c 'select(.subject == "赵云")' visual-passages-curated.jsonl
```

列出当前尚无人工校准视觉证据的游戏英雄：

```sh
jq -r 'select(.curatedVisualPassages == 0) | .name' people-game.jsonl
```

## 时间线、故事与地点

`timeline-curated.jsonl` 是剧情模式的年代骨架：每条事件包含公元年、年号、检索词以及《演义》/《三国志》的并列来源。`timeline-mentions.jsonl` 则保留所有自动命中的年号，适合继续发现支线，但不应取代人工年代校勘。

`stories.jsonl` 从 120 回目录解析出 240 个回目故事。用 `units.jsonl` 可从一回同时取得人物、地点、故事、年代、相貌与典籍线索：

```sh
jq -c 'select(.work == "sanguoyanyi" and .chapter == 46)' units.jsonl
```

地点索引只说明某个名称在何处出现，不解决古今同名、行政区变化、小说地名或精确坐标。制作地图前，应以历史地理资料再校一次。

## 成语、俗语与典籍

`expressions-curated.jsonl` 特意保留来源差异：

- “如鱼得水”见《三国志·诸葛亮传》。
- “乐不思蜀”来自裴注所引《汉晋春秋》。
- “鞠躬尽瘁，死而后已”的通行文字与史料层存在差异；裴注引张俨《默记》所载文本作“鞠躬尽力，死而后已”。
- “草船借箭”“空城计”等是《演义》的文学化或移植故事，不能标成《三国志》史实。
- “周瑜打黄盖，一个愿打一个愿挨”等是后世俗语，原书没有该定型句。

`idiom-matches-moe.jsonl` 只做汉字序列精确匹配。例如某成语四字恰好出现在正文，并不自动证明该书是成语最早典源。进入正式文案前，以 `moeRecordNumber` 回查官方条目，再阅读 `sources` 中的原文上下文。

## 重建与校验

从 `source-materials/` 目录运行：

```sh
node scripts/prepare-source-corpus.mjs --reuse
node scripts/build-knowledge-base.mjs
```

脚本在找不到人工校准段落的 `ref` 或 `query` 时会直接失败，防止上游版本变化后悄悄生成空出处。`manifest.json` 记录输入、输出字节数和 SHA-256；除 `generatedAt` 外，固定输入应生成确定性 JSONL。

## 许可与边界

- 古籍原作属于公版；维基文库整理文本的再利用遵循来源页所列许可和署名要求。
- 官方《成语典》ZIP 保存在 `../raw/` 且不改写。其下载页标示相关资料为 CC BY-ND 3.0 TW；本目录只保存项目自己的匹配索引，不复制完整释义。
- 这是游戏素材研究底稿，不是学术版校勘本。涉及真实历史、族群、容貌评价与地理时，应保留来源层次和不确定性。
